# designpattern

这个目录使用 Go 实现 13 种常见设计模式。每个模式位于独立子目录，并带有对应单元测试。

| 类型 | 示例 |
| --- | --- |
| 创建型 | `simplefactory`、`factory`、`builder`、`singleton` |
| 结构型 | `adapter`、`decorator`、`facade`、`proxy` |
| 行为型 | `chain`、`mediator`、`observer`、`strategy`、`templatemethod` |

## 测试

```sh
go test ./designpattern/...
```
